  - id: m2
    title: "Прими заказ"
    why: "Ты описываешь, как выглядит правильный заказ, и официант начинает сам отказывать неправильным."
    steps:
      - |
        Опиши заказ и тарелку в `app/schemas.py`:
        ```python
        from pydantic import BaseModel, Field


        class AskRequest(BaseModel):
            question: str = Field(min_length=3, max_length=500)
            top_k: int = Field(default=5, ge=1, le=20)


        class AskResponse(BaseModel):
            answer: str
            sources: list[str]
        ```
      - |
        У кухни будет своё место. Выполни `mkdir -p app/services && touch app/services/__init__.py` и напиши `app/services/answer.py`:
        ```python
        def fake_answer(question: str) -> str:
            return f"I will know soon. You asked: {question}"
        ```
      - |
        Пункт меню живёт в роутере. Выполни `mkdir -p app/routers && touch app/routers/__init__.py` и напиши `app/routers/ask.py`:
        ```python
        from fastapi import APIRouter

        from app.schemas import AskRequest, AskResponse
        from app.services.answer import fake_answer

        router = APIRouter()


        @router.post("/ask", response_model=AskResponse)
        def ask(body: AskRequest) -> AskResponse:
            return AskResponse(answer=fake_answer(body.question), sources=[])
        ```
      - "Подключи роутер в `app/main.py`: `from app.routers import ask` наверху и `app.include_router(ask.router)` после `app = FastAPI()`."
      - |
        Отправь правильный заказ:
        ```bash
        curl -s -X POST localhost:8000/ask -H "Content-Type: application/json" -d '{"question":"When does the café open?"}'
        ```
      - "Отправь пустой вопрос: та же команда, но с `'{\"question\":\"\"}'`. Прочитай 422: `loc` говорит `[\"body\",\"question\"]`, а `msg` — `String should have at least 3 characters`."
      - "Попроси слишком много: `'{\"question\":\"hi there\",\"top_k\":100}'`. Теперь `loc` указывает на `top_k`, а сообщение — `Input should be less than or equal to 20`."
      - "Обнови `/docs`. В разделе **Schemas** лежат `AskRequest` и `AskResponse` со всеми твоими ограничениями."
    check: "`/docs` показывает обе модели, а на неправильное тело приходит 422 с названием поля."

        ```python
        class Settings(BaseSettings):

        settings = Settings()
        ```
      - "Используй его в `app/main.py`: `from app.config import settings`, а приложение создавай так: `app = FastAPI(title=settings.app_name)`."

  - id: m4
    title: "Оставь след"
    why: "Каждый запрос получает строку в логе и свой id, чтобы потом его можно было найти."
    steps:
      - |
        Добавь в `app/main.py` middleware — он работает вокруг каждого запроса:
        ```python
        import logging
        import time
        import uuid

        from fastapi import FastAPI, Request

        logging.basicConfig(level=settings.log_level, format="%(asctime)s %(levelname)s %(message)s")
        log = logging.getLogger("quest-api")


        @app.middleware("http")
        async def log_requests(request: Request, call_next):
            request_id = uuid.uuid4().hex[:8]
            start = time.perf_counter()
            response = await call_next(request)
            ms = (time.perf_counter() - start) * 1000
            response.headers["X-Request-ID"] = request_id
            log.info("%s %s %s %.0fms id=%s", request.method, request.url.path, response.status_code, ms, request_id)
            return response
        ```
        Импорты держи в начале файла, строки с `logging` — сразу после импорта `settings`, а middleware — после `app = FastAPI(...)`.
      - "Вызови сервис так, чтобы видеть заголовки: `curl -i localhost:8000/health`. Найди строку `x-request-id: …` и запомни id."
      - "Посмотри в терминал сервера. Там твоя строка, например `2026-03-03 10:42:07,185 INFO GET /health 200 7ms id=c4b3ef29`, с тем же id. Рядом Uvicorn печатает свою короткую строку о запросе; твоя — та, что с id."
      - "Отправь в `/ask` неправильный заказ и найди его строку: в статусе будет `422`."
    check: "Каждый вызов curl добавляет в лог одну твою строку, и id в заголовке совпадает с id в этой строке."
  - id: m5
    title: "Докажи, что работает"
    why: "Ты пишешь тесты, и сервис может доказать, что он в порядке, без того чтобы тебе приходилось всё прокликивать."
    steps:
      - "Установи запускалку тестов: `pip install pytest` и `pip freeze > requirements.txt`."
      - "Сделай тесты пакетом: `mkdir -p tests && touch tests/__init__.py`. Без этого файла `pytest` не сможет импортировать `app` и остановится с `ModuleNotFoundError: No module named 'app'`."
      - |
        Напиши `tests/test_api.py`:
        ```python
        from fastapi.testclient import TestClient

        from app.main import app

        client = TestClient(app)


        def test_health():
            response = client.get("/health")
            assert response.status_code == 200
            assert response.json() == {"status": "ok"}


        def test_ask_valid():
            response = client.post("/ask", json={"question": "When does the café open?"})
            assert response.status_code == 200
            assert "answer" in response.json()


        def test_ask_empty_question():
            response = client.post("/ask", json={"question": ""})
            assert response.status_code == 422
        ```
      - "Запусти их из папки проекта: `pytest -q`. Должно быть `3 passed`."
      - "Сломай код специально: в `/health` верни `\"okay\"` вместо `\"ok\"`. Снова запусти `pytest -q` и прочитай, какой тест упал и почему. Верни как было."
    check: "`pytest -q` показывает 3 passed, а со сломанным кодом падает ровно один тест."
breaks:
  - id: b1
    title: "Заморозь официанта"
    do: "Добавь это в `app/main.py` (и `import time` наверху), сохрани, вызови `curl -s localhost:8000/slow` и сразу же в другом терминале `curl -s -o /dev/null -w \"%{time_total}s\\n\" localhost:8000/health`:\n```python\n@app.get(\"/slow\")\nasync def slow():\n    time.sleep(5)\n    return {\"done\": True}\n```"
    see: "4.701862s"
    why: "`/health` отвечает за миллисекунды, а тут ждал почти 5 секунд. `time.sleep` блокирует, и внутри `async def` он блокирует сам цикл событий: единственный официант застыл у одного столика, и ждут все остальные."
    fix: "Используй вызов, который можно ждать: `await asyncio.sleep(5)` (и `import asyncio`). Или сделай функцию обычной `def`: тогда FastAPI запустит её в пуле потоков, подальше от официанта. Потом удали `/slow`."

    title: "Пожар на кухне"

У тебя есть код на Python, который отвечает на вопрос. Пока что его можешь
запустить только ты — руками и один раз. Этот уровень превращает его в
**сервис**: программу, которая продолжает работать, ждёт запросов от кого
угодно в сети и вежливо отвечает на каждый — месяцами.

<Analogy />

## Запрос и ответ

Любое обращение к сервису — это один **запрос** (request) и один **ответ**
(response). У запроса есть **метод** (что сделать: `GET` — прочитать,
`POST` — что-то отправить), **путь** (какой эндпоинт: `/ask`),
**заголовки** (заметки о запросе) и иногда **тело** — данные, обычно в
JSON. Ответ приходит с **кодом ответа**, заголовками и своим телом.

## Твой первый сервис

Создай для проекта отдельный набор инструментов и поставь в него FastAPI:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install "fastapi[standard]"
```

А дальше целый сервис — это шесть строк:

```python
from fastapi import FastAPI
app = FastAPI()

@app.get("/health")
def health():
    return {"status": "ok"}
```

Запусти `fastapi dev main.py` и открой `http://localhost:8000/docs`.
Эту страницу FastAPI написал за тебя по твоему же коду: все эндпоинты, и
каждый можно сразу попробовать. Ты возвращаешь словарь Python, а клиент
получает JSON.

## Официант проверяет заказ

Незнакомцы пришлют тебе что угодно. Вместо того чтобы проверять каждое
поле руками, ты описываешь правильный заказ моделью Pydantic:

```python
class AskRequest(BaseModel):
    question: str = Field(min_length=3, max_length=500)
    top_k: int = Field(default=5, ge=1, le=20)
```

Тело, которое не подходит под модель, до твоего кода не доходит. Клиент
получает **422** и список `detail`, где точно сказано, какое поле не так и
почему. Это и есть валидация.

Коды ответа — это то, как ты отвечаешь. Вот те, что будут нужны
постоянно:

| Код | Значит |
|---|---|
| 200 | Всё хорошо, вот ответ |
| 201 | Создано что-то новое |
| 400 | Запрос не имеет смысла |
| 401 | А вы кто? Сначала войдите |
| 404 | Такого нет |
| 422 | Не могу разобрать заказ |
| 500 | Что-то сломалось у нас |

Если ты знаешь, что чего-то нет, скажи об этом нарочно:
`raise HTTPException(status_code=404, detail="Document not found")`.

## Один официант, много столиков: `async def` и `def`

FastAPI обслуживает запросы с помощью **цикла событий** (event loop):
одного официанта, который бегает между многими столиками. Пока готовится
один заказ — запрос в базу данных, вызов другого API, — он обслуживает
остальных. Это работает, только пока он нигде не застывает.

<Diagram name="event-loop" />

Правило такое:

- `async def` — только если всё медленное внутри идёт через `await`.
- Обычная `def` — для кода, который блокирует: `time.sleep`, большинство
  библиотек для файлов и баз данных без `async`. Такие функции FastAPI
  запускает в пуле потоков, подальше от официанта.

Блокирующий вызов внутри `async def` замораживает сразу все запросы. В
«Сломай специально» ты устроишь ровно это — и будешь узнавать с первого
взгляда.

## Настройки и бумажный след

Адреса, пароли и ключи на ноутбуке и на сервере разные. В коде им не
место. `pydantic-settings` читает их из переменных окружения или файла
`.env` в типизированный класс `Settings`. Файл `.env` попадает в
`.gitignore` в первый же день: секрет, который попал в историю git, там и
остаётся.

А ещё сервис должен рассказывать, что он делал. Используй `logging`, а не
`print`: одна строка на запрос — метод, путь, статус, сколько это заняло и
**id запроса**. Когда кто-то скажет «мой запрос упал в 10:42», этот id
приведёт тебя прямо к нужной строке.

чтобы у каждой работы было своё место:

## Что запомнить

1. **Модель описывает правильный заказ.** На неправильный приходит 422 с названием поля.
2. **Коды ответа — это лицо официанта.** Выбирай их осознанно.
3. **Не блокируй официанта.** `async def` — с `await`, обычная `def` — для блокирующего кода.
4. **Секреты живут в `.env`, а не в git. Каждый запрос оставляет одну строку в логе.**

Миссии собирают `quest-api` — сервис, который будет расти следующие пять уровней.
