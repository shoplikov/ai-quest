  - id: m2
    title: "Прими заказ"
    why: "Ты описываешь правильный заказ, и официант начинает сам отказывать неправильным."
    steps:
      - |
        Опиши заказ и тарелку в `app/schemas.py`:
        ```python
        from pydantic import BaseModel, Field


        class AskRequest(BaseModel):
            question: str = Field(min_length=3, max_length=500)
            top_k: int = Field(default=5, ge=1, le=20)


        class AskResponse(BaseModel):
            answer: str
            sources: list[str]
        ```
      - |
        Выдели кухне своё место:
        ```bash
        mkdir -p app/services && touch app/services/__init__.py
        ```
      - |
        Напиши `app/services/answer.py`:
        ```python
        def fake_answer(question: str) -> str:
            return f"I will know soon. You asked: {question}"
        ```
      - |
        Сделай место для меню:
        ```bash
        mkdir -p app/routers && touch app/routers/__init__.py
        ```
      - |
        Напиши `app/routers/ask.py`:
        ```python
        from fastapi import APIRouter

        from app.schemas import AskRequest, AskResponse
        from app.services.answer import fake_answer

        router = APIRouter()


        @router.post("/ask", response_model=AskResponse)
        def ask(body: AskRequest) -> AskResponse:
            return AskResponse(answer=fake_answer(body.question), sources=[])
        ```
      - |
        Подключи роутер в `app/main.py`:
        ```python
        from app.routers import ask      # наверху

        app.include_router(ask.router)   # после app = FastAPI()
        ```
      - |
        Отправь правильный заказ:
        ```bash
        curl -s -X POST localhost:8000/ask -H "Content-Type: application/json" -d '{"question":"When does the café open?"}'
        ```
      - |
        Отправь пустой вопрос:
        ```bash
        curl -s -X POST localhost:8000/ask -H "Content-Type: application/json" -d '{"question":""}'
        ```
        422 называет поле: `loc` — это `["body","question"]`, `msg` — `String should have at least 3 characters`.
      - |
        Попроси слишком много:
        ```bash
        curl -s -X POST localhost:8000/ask -H "Content-Type: application/json" -d '{"question":"hi there","top_k":100}'
        ```
        Теперь `loc` указывает на `top_k`: `Input should be less than or equal to 20`.
      - "Обнови `/docs`. В разделе **Schemas** лежат обе модели со всеми твоими ограничениями."
    check: "`/docs` показывает обе модели, а на неправильное тело приходит 422 с названием поля."

    title: "Настройки и секреты"

        Напиши `app/config.py`:
        ```python
        from pydantic_settings import BaseSettings, SettingsConfigDict


        class Settings(BaseSettings):
            model_config = SettingsConfigDict(env_file=".env", extra="ignore")

            app_name: str = "quest-api"
            log_level: str = "INFO"
            llm_base_url: str = "http://localhost:11434/v1"


        settings = Settings()
        ```

      - |
        Используй его в `app/main.py`:
        ```python
        from app.config import settings          # наверху

        app = FastAPI(title=settings.app_name)   # вместо app = FastAPI()
        ```

  - id: m4
    title: "Оставь след"
    why: "Каждый запрос получает строку в логе и свой id, чтобы потом его можно было найти."
    steps:
      - |
        Добавь в `app/main.py` middleware. Он работает вокруг каждого запроса:
        ```python
        import logging
        import time
        import uuid

        from fastapi import FastAPI, Request

        logging.basicConfig(level=settings.log_level, format="%(asctime)s %(levelname)s %(message)s")
        log = logging.getLogger("quest-api")


        @app.middleware("http")
        async def log_requests(request: Request, call_next):
            request_id = uuid.uuid4().hex[:8]
            start = time.perf_counter()
            response = await call_next(request)
            ms = (time.perf_counter() - start) * 1000
            response.headers["X-Request-ID"] = request_id
            log.info("%s %s %s %.0fms id=%s", request.method, request.url.path, response.status_code, ms, request_id)
            return response
        ```
        Импорты — в начале файла, строки с `logging` — сразу после импорта `settings`, middleware — после `app = FastAPI(...)`.
      - |
        Вызови сервис с показом заголовков и найди строку `x-request-id: …`:
        ```bash
        curl -i localhost:8000/health
        ```
      - |
        Посмотри в терминал сервера. В твоей строке тот же id:
        ```text
        2026-03-03 10:42:07,185 INFO GET /health 200 7ms id=c4b3ef29
        ```
        Рядом Uvicorn печатает свою короткую строку о запросе. Твоя — та, что с id.
      - "Отправь в `/ask` неправильный заказ и найди его строку. В статусе будет `422`."
    check: "Каждый вызов curl добавляет в лог одну твою строку, и id в заголовке совпадает с id в этой строке."

breaks:
  - id: b1
    title: "Заморозь официанта"
    do: |
      Добавь это в `app/main.py`, а наверху — `import time`:
      ```python
      @app.get("/slow")
      async def slow():
          time.sleep(5)
          return {"done": True}
      ```
      Вызови `curl -s localhost:8000/slow` и сразу же, в другом терминале:
      ```bash
      curl -s -o /dev/null -w "%{time_total}s\n" localhost:8000/health
      ```
    see: "4.701862s"
    why: "`/health` отвечает за миллисекунды, а тут ждал почти 5 секунд. `time.sleep` блокирует, и внутри `async def` он блокирует сам цикл событий: единственный официант застыл у одного столика, и ждут все остальные."
    fix: "Используй вызов, который можно ждать: `await asyncio.sleep(5)` (и `import asyncio`). Или сделай функцию обычной `def`: тогда FastAPI запустит её в пуле потоков, подальше от официанта. Потом удали `/slow`."

## Запрос и ответ

**Любое обращение — это один запрос и один ответ.**

<Diagram name="request-response" />

У запроса есть **метод** (`GET` — прочитать, `POST` — отправить), **путь**
(`/ask`), **заголовки** и иногда **тело**, обычно в JSON. Ответ приходит с
**кодом ответа**, заголовками и своим телом.

## Твой первый сервис

**Целый сервис — это шесть строк.**

```python
from fastapi import FastAPI
app = FastAPI()

@app.get("/health")
def health():
    return {"status": "ok"}
```

Запусти `fastapi dev main.py` и открой `http://localhost:8000/docs`. Эту
страницу FastAPI написал по твоему коду: все эндпоинты, и каждый можно
сразу попробовать.

## Официант проверяет заказ

**Опиши правильный заказ один раз. Неправильные до твоего кода не дойдут.**

```python
class AskRequest(BaseModel):
    question: str = Field(min_length=3, max_length=500)
    top_k: int = Field(default=5, ge=1, le=20)
```

Тело, которое не подходит под модель, получает **422** и список `detail`,
где названо неправильное поле. Кодами ответа ты отвечаешь клиенту:

  <li class="ok"><b>201</b> Создано что-то новое</li>

## Один официант, много столиков: `async def` и `def`

**Один официант обслуживает все столики. Ему нельзя застывать.**

<Diagram name="event-loop" />

Этот официант — **цикл событий** (event loop). Пока готовится один заказ —
запрос в базу данных, вызов другого API, — он обслуживает остальных.
Правило такое:

- `async def` — только если всё медленное внутри идёт через `await`.
- Обычная `def` — для кода, который блокирует, например `time.sleep`.
  Такие функции FastAPI запускает в пуле потоков, подальше от официанта.

Блокирующий вызов внутри `async def` замораживает сразу все запросы. В
«Сломай специально» ты устроишь ровно это.

## Настройки и бумажный след

**Секреты живут в `.env`. Каждый запрос оставляет строку в логе.**

Адреса, пароли и ключи на ноутбуке и на сервере разные, поэтому в коде им
не место. `pydantic-settings` читает их из файла `.env`, а `.env` попадает
в `.gitignore` в первый же день.

Используй `logging`, а не `print`: метод, путь, статус, длительность и
**id запроса**. Когда кто-то скажет «мой запрос упал в 10:42», этот id
приведёт тебя прямо к нужной строке.

## Что запомнить

1. **Модель описывает правильный заказ.** На неправильный приходит 422 с названием поля.
2. **Коды ответа — это лицо официанта.** Выбирай их осознанно.
3. **Не блокируй официанта.** `async def` — с `await`, обычная `def` — для блокирующего кода.
4. **Секреты живут в `.env`, а не в git. Каждый запрос оставляет одну строку в логе.**
