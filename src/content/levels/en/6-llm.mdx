        ```python
        import logging
        import time
        from pathlib import Path

        from app.config import settings
        from app.llm import client

        log = logging.getLogger("quest-api")
        PROMPTS = Path(__file__).parents[2] / "prompts"
        ANSWER_PROMPT = "answer_v1"


        def load_prompt(name: str) -> str:
            return (PROMPTS / f"{name}.txt").read_text()


        def llm_answer(question: str) -> str:
            start = time.perf_counter()
            response = client.chat.completions.create(
                model=settings.llm_model,
                messages=[
                    {"role": "system", "content": load_prompt(ANSWER_PROMPT)},
                    {"role": "user", "content": question},
                ],
                temperature=0.2,
                max_tokens=300,
            )
            ms = (time.perf_counter() - start) * 1000
            choice = response.choices[0]
            log.info(
                "llm model=%s prompt=%s in=%d out=%d %.0fms finish=%s",
                settings.llm_model, ANSWER_PROMPT, response.usage.prompt_tokens,
                response.usage.completion_tokens, ms, choice.finish_reason,
            )
            return choice.message.content
        ```

      - |
        Add a streaming version to `app/services/answer.py` (with `from collections.abc import Iterator` at the top):
        ```python
        def llm_stream(question: str) -> Iterator[str]:
            start = time.perf_counter()
            first_token_ms = None
            out_tokens = 0
            stream = client.chat.completions.create(
                model=settings.llm_model,
                messages=[
                    {"role": "system", "content": load_prompt(ANSWER_PROMPT)},
                    {"role": "user", "content": question},
                ],
                temperature=0.2,
                max_tokens=300,
                stream=True,
                stream_options={"include_usage": True},
            )
            for chunk in stream:
                if chunk.choices and chunk.choices[0].delta.content:
                    if first_token_ms is None:
                        first_token_ms = (time.perf_counter() - start) * 1000
                    yield chunk.choices[0].delta.content
                if chunk.usage:
                    out_tokens = chunk.usage.completion_tokens
            total_ms = (time.perf_counter() - start) * 1000
            log.info(
                "llm stream model=%s out=%d first_token=%.0fms total=%.0fms",
                settings.llm_model, out_tokens, first_token_ms or 0, total_ms,
            )
        ```
        `include_usage` asks the server for one last chunk with the token counts.

        ```python
            text: str = Field(min_length=3, max_length=2000)


        class Complaint(BaseModel):
        ```

        Write `prompts/extract_v1.txt`:
        ```text
        You read one guest complaint about the Otter Café.
        Return JSON with:
        - category: one of food, drinks, service, cleanliness, price, other
        - urgency: 1 (a small wish) to 5 (someone may get hurt or sick)
        - summary: one short sentence in the language of the complaint
        ```
      - |
        Add the extraction to `app/services/answer.py` (with `from pydantic import ValidationError` and `from app.schemas import Complaint` at the top):
        ```python
        EXTRACT_PROMPT = "extract_v1"


        class ExtractionFailed(Exception):
            pass


        def extract_complaint(text: str) -> Complaint:
            schema = {"name": "complaint", "schema": Complaint.model_json_schema()}
            for attempt in (1, 2):
                response = client.chat.completions.create(
                    model=settings.llm_model,
                    messages=[
                        {"role": "system", "content": load_prompt(EXTRACT_PROMPT)},
                        {"role": "user", "content": text},
                    ],
                    temperature=0,
                    max_tokens=300,
                    response_format={"type": "json_schema", "json_schema": schema},
                )
                raw = response.choices[0].message.content
                try:
                    return Complaint.model_validate_json(raw)
                except ValidationError as error:
                    log.warning("extract attempt %d failed: %s", attempt, error.errors()[0]["msg"])
            raise ExtractionFailed("the model did not return a valid complaint")
        ```
        The schema goes along with the request, so the server can hold the model to it — and Pydantic checks anyway.
      - |
        Add the route (import `HTTPException`, the two schemas, `extract_complaint` and `ExtractionFailed`):
        ```python
        @router.post("/extract", response_model=Complaint)
        def extract(body: ExtractRequest) -> Complaint:
            try:
                return extract_complaint(body.text)
            except ExtractionFailed as error:
                raise HTTPException(status_code=502, detail=str(error))
        ```
        A broken answer from the model is not the caller's fault, so it gets `502`, not `422`.

        Give the client manners in `app/llm.py`: wait at most 30 seconds, try at most twice more.

      - |
        Write `scripts/load_test.py`. Twenty questions, at most four at a time — the `Semaphore` is the bouncer at the door:
        ```python
        import asyncio
        import time

        from openai import AsyncOpenAI

        from app.config import settings

        client = AsyncOpenAI(base_url=settings.llm_base_url, api_key=settings.llm_api_key, timeout=30, max_retries=2)
        limit = asyncio.Semaphore(4)
        in_flight = 0


        async def ask(number: int) -> float:
            global in_flight
            async with limit:
                in_flight += 1
                print(f"start {number:2}  in flight: {in_flight}")
                start = time.perf_counter()
                await client.chat.completions.create(
                    model=settings.llm_model,
                    messages=[{"role": "user", "content": f"Tell me fun fact number {number} about otters, in one sentence."}],
                    max_tokens=80,
                )
                seconds = time.perf_counter() - start
                in_flight -= 1
                print(f"done  {number:2}  {seconds:.1f}s")
                return seconds


        async def main() -> None:
            start = time.perf_counter()
            durations = await asyncio.gather(*(ask(n) for n in range(1, 21)))
            print(f"20 calls in {time.perf_counter() - start:.1f}s, slowest {max(durations):.1f}s")


        asyncio.run(main())
        ```
      - |
        Rebuild and run it:

        Watch `in flight`: it climbs to 4 and never higher. Write down the total time and the slowest call.

Until now `/ask` has been pretending. Now it asks a real language model,
and you treat it like any other service over a network: with limits,
timeouts, logs and a healthy distrust of what comes back.

## The shape of the API

**One client speaks to every model server. You only change the address.**

```python
from openai import OpenAI

client = OpenAI(base_url=settings.llm_base_url, api_key=settings.llm_api_key)
response = client.chat.completions.create(
    model=settings.llm_model,
    messages=[
        {"role": "system", "content": "You answer in one short sentence."},
        {"role": "user", "content": "What is a port?"},
    ],
    temperature=0.2,
    max_tokens=200,
)
print(response.choices[0].message.content, response.usage)
```

vLLM, Ollama and many others speak OpenAI's API. The **system** message
sets the rules; the **user** message is the question.

## Tokens and the context window

**Prompt tokens plus `max_tokens` must fit in one window.**

<Diagram name="context-window" />

**Tokens** are pieces of words. The window holds the system prompt, any
documents, the question — and the answer still to be written.

Every response says what it cost, in `usage`, and why it stopped, in
`finish_reason`:

<ul class="chips">
  <li class="ok"><b>stop</b> The model finished</li>
  <li class="you"><b>length</b> It ran out of <code>max_tokens</code> mid-thought</li>
</ul>

<Reveal summary="What happens when it does not fit?">
vLLM refuses with a `400`. Ollama quietly cuts off the start of your
prompt and answers anyway. Reading `usage` is how you find out.
</Reveal>

## Streaming

**Send each token as it is made. Speed is two numbers.**

<Diagram name="streaming-timeline" />

Without streaming, you wait for the last token before you see the first.
With it, each piece arrives as a **server-sent event**: a line that
starts with `data:`.

- **Time to first token**: how long the user stares at nothing.
- **Tokens per second** after that.

## Things fail

**Give every client a `timeout=` and a `max_retries=`.**

<ul class="chips">
  <li><b>timeout</b> No answer in time</li>
  <li class="you"><b>429</b> Too Many Requests: you push too hard</li>
  <li class="us"><b>5xx</b> The server is restarting</li>
</ul>

The client waits a little longer before each new try. **Never retry
forever**: a stuck server plus endless retries is a traffic jam you built
yourself.

## Structured output

**Ask for JSON that matches a schema. Validate it anyway.**

Pass the schema along (`response_format`) so the server can hold the
model to it, then check with Pydantic. Not valid? Retry once, then fail
clearly. For extraction, use `temperature=0`: you want the same form, not
creativity.

## Prompts are code

**A prompt lives in a file, in git, with a version in its name.**

Change one thing at a time, and compare on the same questions:
`answer_v1.txt`, then `answer_v2.txt`. "I tweaked the prompt and now it
feels better" is not a result.

## Many requests at once

**Wait for many answers at once, with a bouncer at the door.**

```python
limit = asyncio.Semaphore(4)

async def ask(question: str) -> str:
    async with limit:
        response = await client.chat.completions.create(...)
        return response.choices[0].message.content
```

With the async client, one process waits for many answers (Level 3's
event loop). The server has limits too, so the semaphore lets at most
four calls in at a time.

## Where the model lives

**The model sits on a GPU behind a port. You will mostly be a caller.**

<Reveal summary="What is on the other side of the port?">
A server such as vLLM loads the model onto a GPU once and serves many
callers: `vllm serve <model> --port 8000`. The weights fill most of the
GPU's memory before the first question arrives; `nvidia-smi` shows how
much.
</Reveal>

## What to remember

1. **Prompt plus `max_tokens` must fit the window.** Read `usage`.
2. **Check `finish_reason`.** `length` means unfinished.
3. **Every call has a timeout and a retry limit.** Never retry forever.
4. **Never trust model JSON without validating it.**
5. **Latency is two numbers:** time to first token, and tokens per second.
